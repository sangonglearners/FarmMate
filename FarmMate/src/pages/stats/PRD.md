# 통계 페이지 PRD (Product Requirements Document)

## 1. 개요

| 항목 | 내용 |
|------|------|
| **제품** | FarmMate 통계 |
| **대상 화면** | 통계 메뉴(메뉴바) 진입 시 노출되는 통계 페이지 |
| **목적** | 농가의 매출·순수익·비용을 기준 날짜·지표·기간 단위에 따라 조회·시각화 |

---

## 2. 기준 날짜 (Reference Date)

| 요구사항 | 상세 |
|----------|------|
| **정의** | 모든 기간 계산의 기준이 되는 날짜. 사용자가 선택 가능하다. |
| **초기값** | 앱 로드 시 **오늘 날짜** (yyyy-MM-dd). |
| **UI** | 상단에 **날짜 입력 위젯**(`<input type="date">`)으로 표시. 클릭 시 날짜 변경 가능. |
| **반영 범위** | 일/월/분기/연 **기간 구간**의 끝 시점 계산에 사용. (시작은 단위별 고정 기간으로 역산.) |

## 3. 지표 모드 (매출 / 순수익 / 비용)

| 요구사항 | 상세 |
|----------|------|
| **옵션** | **매출** \| **순수익** \| **비용** 중 하나 선택. |
| **UI** | 토글 형태(세그먼트 컨트롤). 선택된 항목은 초록색 배경으로 강조. |
| **반영 범위** | • 요약 카드(평균·누적 등) • 추이 차트 • 작물별 비중 차트 • 기타 매출/비용 기반 지표. |
| **계산** | • **매출**: 장부 `revenueAmount` 합계. • **비용**: 장부 비용 항목 합계. • **순수익**: 매출 − 비용. |

## 4. 보기 단위 및 고정 기간 (일 / 월 / 분기 / 연)

기준 날짜를 기준으로 **고정된 길이의 구간**을 사용한다.

| 보기 단위 | 구간 정의 | 비고 |
|-----------|-----------|------|
| **일** | 기준 날짜 포함 **지난 90일** | 요일별 평균 등 일 단위 집계에 사용. |
| **월** | 기준 날짜가 속한 달의 말일까지 **지난 12개월** | 12개월. |
| **분기** | 기준 날짜가 속한 분기 말까지 **지난 12분기**(3년) | 12분기. |
| **연** | 기준 날짜가 속한 연도 말까지 **지난 5년** | 5개 연도. |

- **데이터 필터링**: 위 구간(`normalizedStart` ~ `normalizedEnd`) 안에 **작업 종료일(또는 예정일)**이 들어오는 장부·작업만 사용.
- **차트 표시**: 월/분기/연은 “데이터가 처음 기록된 시점”부터만 그리며, 그 이전 빈 구간은 표시하지 않음. (일은 90일 전체 구간 유지.)

---

## 5. 차트 시작 시점 (데이터 최초 기록)

| 요구사항 | 상세 |
|----------|------|
| **목적** | 데이터가 없는 기간을 차트 앞쪽에 길게 보여주지 않기 위함. |
| **적용 단위** | **월 / 분기 / 연**에만 적용. **일**은 적용하지 않음(요일별 평균 구조 유지). |
| **규칙** | 1) 기준 구간 내에서 **장부가 연결된 작업**만 대상. 2) 해당 작업들의 **종료일(또는 예정일)** 중 **가장 이른 날**을 구함. 3) 그 날이 속한 **월/분기/연의 시작일**을 차트 시작일(`chartStart`)로 사용. 4) 차트 종료일(`chartEnd`)은 기존 구간 끝(`normalizedEnd`) 유지. |
| **데이터 없음** | 구간 내에 해당하는 장부·작업이 없으면 차트는 전체 기준 구간을 그대로 사용. |

---

## 6. 기준 구간 표시 (Criterion Label)

| 요구사항 | 상세 |
|----------|------|
| **위치** | **매출액(또는 순수익/비용) 추이** 차트 영역에서, **일/월/분기/연 토글 오른쪽**에 같은 줄로 표시. |
| **형식** | 선택된 보기 단위에 따라 다음 형식으로 **실제 차트에 쓰인 구간**(`chartStart` ~ `chartEnd`) 표시. |
| **표기 규칙** | • **일**: `25.01.01~25.03.31 일` (YY.MM.DD~YY.MM.DD) • **월**: `25.03~26.03 월` (YY.MM~YY.MM) • **분기**: `23.Q2~26.Q1 분기` (YY.Qn~YY.Qn) • **연**: `21~25 연` (YY~YY) |

---

## 7. 추이 차트 표시 규칙

| 항목 | 규칙 |
|------|------|
| **X축 라벨** | • **일**: 요일(일, 월, …, 토). • **월**: `25.01`, `25.02` 형태(YY.MM). • **분기**: `24.Q1`, `24.Q3`, `25.Q1` 등 — **두 개마다 한 번씩**만 표시(월과 동일한 간격). • **연**: 연도. (모바일에서는 간격 조정 가능.) |
| **Y축** | 금액. 단위: 천원. 소수점 없이 정수만 표시. |
| **데이터 소스** | 작업에 연결된 장부. 작업의 **종료일(또는 예정일)**로 해당 월/분기/연에 포함 여부 판단. |

---

## 8. 기타 통계 블록

- **요약 카드**: 선택된 지표(매출/순수익/비용)에 따른 평균·누적 등. 순수익일 때는 “평균 순수익”, “누적 순수익”만 표시.
- **작물별 매출(또는 비용/순수익) 비중**: 원형 차트 + 목록. **기타 포함 최대 6개**, **기타는 항상 맨 아래**.
- **작물 구성**: 작물별 이랑 사용. 동일하게 **기타 포함 최대 6개**, **기타 맨 아래**.
- **작업 완료율**, **농장별 작업 상태** 등은 기존 로직 유지. 기준 날짜·지표·보기 단위와 일관된 구간 내 데이터로 계산.
