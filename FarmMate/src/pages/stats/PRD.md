# 통계 페이지 PRD (Product Requirements Document)

## 1. 개요

| 항목 | 내용 |
|------|------|
| **제품** | FarmMate 통계 |
| **대상 화면** | 통계 메뉴(메뉴바) 진입 시 노출되는 통계 페이지 |
| **목적** | 사용자가 지정한 기간(시작일-종료일) 기준으로 매출/비용/순수익과 작업 현황을 일관되게 조회·비교한다. |

---

## 2. 기간 설정 (시작일-종료일)

| 요구사항 | 상세 |
|----------|------|
| **정의** | 통계 집계의 기준은 단일 기준일이 아닌 **시작일-종료일** 범위이다. |
| **초기값** | 앱 로드 시 **종료일=오늘**, **시작일=작년의 오늘**으로 기본 설정한다. |
| **UI** | 상단에 시작일/종료일 날짜 입력 위젯 2개를 노출한다. |
| **반영 범위** | 통계 페이지 내 매출/작업 관련 모든 집계와 차트는 해당 기간을 기준으로 계산한다. |

---

## 3. 내 농장의 수익 현황은?

### 3.1 필터

| 항목 | 요구사항 |
|------|----------|
| **필터 구성** | 장부 관리와 동일한 형태의 필터를 제공한다. |
| **필터 1 (지표)** | `매출` / `비용` / `순수익` 중 1개 선택 |
| **필터 2 (집계 방식)** | `상세` / `평균` 중 1개 선택 |
| **기본 선택값** | 지표=`매출`, 집계 방식=`상세` |
| **적용 대상** | `매출액 추이`, `작물별 매출 비중` 2개 차트 모두 동일하게 적용 |

### 3.2 블록 구성

| 항목 | 요구사항 |
|------|----------|
| **제거** | 기존 `평균 매출/누적 매출` 박스 제거 |
| **차트 배치** | `매출액 추이`, `작물별 매출 비중`을 **하나의 박스** 안에서 함께 제공 |
| **토글** | 두 차트 모두 `일/월/분기/연` 토글을 공통 사용 |

### 3.3 상세/평균별 데이터 집계 규칙

#### 상세일 때

| 단위 | 집계 기준 |
|------|-----------|
| **일** | 최근 7일 데이터를 표시하고, 버튼으로 1주 단위 이전/다음 구간 이동 가능 |
| **월** | 종료일 기준 이전 12개월 |
| **분기** | 종료일 기준 이전 4개 분기(Q4) |
| **연** | 종료일 기준 이전 5개년 |

#### 평균일 때

| 단위 | 집계 기준 |
|------|-----------|
| **일** | 선택한 전체 기간 기준 요일별 평균 |
| **월** | 선택한 전체 기간 기준 월별 평균 |
| **분기** | 선택한 전체 기간 기준 분기별 평균 |
| **연** | 표시하지 않음 |

### 3.4 표시 규칙

| 항목 | 요구사항 |
|------|----------|
| **선행 데이터 기준 제거** | `데이터가 처음 발생한 날짜부터 표시` 규칙을 완전 제거한다. |
| **구간 강제 표시** | 사용자가 지정한 조건의 전체 구간(단위별 슬롯)을 항상 표시한다. |
| **값 없음 처리** | 해당 구간에 데이터가 없으면 `0원`으로 표시한다. |
| **동일 규칙 적용** | 위 규칙은 `매출액 추이`, `작물별 매출 비중` 모두에 동일 적용한다. |

## 4. 내 농장의 작업 현황은?

| 항목 | 요구사항 |
|------|----------|
| **섹션 제목** | `내 농장의 작업 상황은?` |
| **박스 1** | `작물 구성`을 별도 박스로 노출 |
| **박스 2** | `농장별 작업 상태`를 별도 박스로 노출 |
| **집계 기간** | 두 박스 모두 상단 시작일-종료일 범위를 기준으로 집계/표시 |
| **배치 원칙** | 두 박스는 서로 분리된 UI 블록으로 구성 |

---

## 5. 제거/변경 항목 정리

| 구분 | 내용 |
|------|------|
| **제거** | `평균 매출/누적 매출` 박스 제거 |
| **제거** | `작업 완료율` 박스 제거 |
| **변경** | 단일 기준 날짜 -> 시작일-종료일 범위 기준 |
| **변경** | 데이터 최초 발생 시점부터 표시 규칙 삭제, 미존재 값은 0원 표시 |

---

## 6. 요약 표

| 조건 | 설명 |
|------|------|
| **기간 기본값** | 시작일=작년의 오늘, 종료일=오늘 |
| **필터 기본값** | 지표=매출, 집계 방식=상세 |
| **공통 토글** | 일/월/분기/연 (단, 평균 모드에서는 연 미표시) |
| **상세 집계** | 일=최근 7일(주 단위 이동), 월=12개월, 분기=4분기, 연=5개년 |
| **평균 집계** | 일=요일 평균, 월=월 평균, 분기=분기 평균, 연=미표시 |
| **표시 정책** | 지정한 전체 구간 강제 표시, 데이터 없으면 0원 |
| **작업 상황 집계 기준** | 작물 구성/농장별 작업 상태 모두 시작일-종료일 기준 |
